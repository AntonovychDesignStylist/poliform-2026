# Poliform 2026 · Milan Design Week

Анимированная презентация для Antonovych Design. Открывается в любом браузере.

## Как смотреть
Распакуйте папку целиком и откройте `index.html` двойным кликом.
Важно: держать `index.html` и папку `media` вместе.

Управление: `←` `→` или пробел — листать, свайп на телефоне,
`Esc` — обзор всех слайдов, `F` — во весь экран, `♪` — звук у видео.

## Как выложить в интернет (GitHub Pages)
1. Создать репозиторий на github.com, например `poliform-2026`
2. Загрузить туда всё содержимое этой папки (кнопка **Add file → Upload files**)
3. Settings → Pages → Source: `main`, папка `/ (root)` → Save
4. Через минуту ссылка: `https://<ваш-логин>.github.io/poliform-2026/`

## Как менять контент
Всё в файле `slides.js`: порядок слайдов, тексты, пути к фото и видео.
Код трогать не нужно. Новые файлы класть в `media/img` и `media/video`.

## Что внутри
- Фото и видео — оригиналы, без пересжатия и перекодирования
- Фотографии не затемнены, не обрезаны, пропорции не изменены
- Палитра из брендбука: #151313, #231F20, #4A4542, #D1CDC7, #F5F5F5, Satin Gold #C68346 (только акценты)
- Шрифт Gilroy подключён внутри — выглядит одинаково на любом устройстве

## Порядок кадров
Часть Palazzo Clerici идёт строго в порядке нумерации ваших файлов (1, 2, 3 … 261).
Часть «Шоурум в Милане» пока сгруппирована по помещениям — переставлю, когда пронумеруете.
Вертикальные кадры стоят по два на слайд, чтобы заполнять экран без обрезки.
